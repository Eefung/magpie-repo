# 分流标签

这些 skill 用五个规范化的分流角色说话。本文件把这些角色映射到本仓库 issue 追踪器里实际使用的标签字符串。

| 规范角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要先评估这个 issue |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，可以交给 AFK agent 做 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不打算处理 |

当某个 skill 提到某个角色（例如"打上 AFK-ready 标签"），就用表里对应的标签字符串。

要换成别的词汇，改"本仓库的标签"这一列即可。
